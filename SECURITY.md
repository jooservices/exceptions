# Security Policy

## Supported versions

| Version line | Status |
| --- | --- |
| `4.0.x` | Current supported line |
| Earlier lines | End of life; archived and unsupported |

## Reporting a vulnerability

Do not open public issues for suspected vulnerabilities. Use GitHub [private
vulnerability reporting](https://github.com/jooservices/exceptions/security/advisories/new)
or email [admin@jooservices.com](mailto:admin@jooservices.com).

Include the affected version, impact, and a minimal reproduction without
credentials or real secrets. CI scans dependencies, committed secrets, and
PHP source; release tags additionally require the complete quality gate.
